# Análise de mercado — TERON OS

## O que é o produto

Sistema operacional empresarial para **agências / studios de software**:
- Bot WhatsApp (captação + discovery + proposta)
- Proposta interativa (simulador, contrato OTP, pagamento)
- Painel admin (CRM, propostas, projetos, financeiro)
- Workstation do cliente (onboarding, checklist, status)

Tudo no mesmo banco — admin e cliente sincronizados.

## Existe algo assim no mercado?

**Sim, em partes — não como um pacote único bem feito no Brasil.**

| Ferramenta | O que cobre | O que falta vs TERON |
|------------|-------------|----------------------|
| **Pipedrive / RD Station / Kommo** | CRM + pipeline | Sem proposta interativa + workstation + bot deep-linked |
| **Quoter / PandaDoc / Clicksign** | Proposta / contrato | Sem bot + OS de projeto |
| **Notion + manuais** | Workspace cliente | Não é produto comercial fechado |
| **ManyChat / BotConversa** | Bot WhatsApp | Sem OS / proposta / painel de projeto |
| **Agidesk / Movidesk** | Suporte | Não é comercial + entrega de software |
| **Monday / ClickUp** | Projetos | Sem bot BR + proposta + pagamento nativo |

**Conclusão:** o diferencial é a **cadeia fechada**:
WhatsApp → proposta viva → assinatura → pagamento → workstation → você gerencia no mesmo lugar.

No exterior há stacks parecidas (HubSpot + PandaDoc + Slack + custom), mas caras e pouco adaptadas ao WhatsApp brasileiro.

## Para quem vender

### Ideal (ICP)
1. **Agências digitais e product studios** (5–40 pessoas) que vendem site, sistema, app, automação
2. **Freelas sênior / consultores** que fecham R$ 5k–80k por projeto e perdem tempo no WhatsApp
3. **Software houses B2B** que querem padronizar orçamento e onboarding

### Secundário
- Empresas de serviço que vendem por proposta (arquitetura, consultoria, educação B2B)
- White-label para o bot multi-nicho (barbearia, clínica, etc.) — outro produto, mesma base

### Evitar no início
- Enterprise gigante (ciclo longo, compliance)
- Microempreendedor que só quer um chatbot barato

## Quanto custaria desenvolver (referência de mercado)

Estimativa para um produto **no nível atual + polish de produção** (BR, 2026):

| Escopo | Faixa |
|--------|--------|
| MVP bot + proposta + painel básico | R$ 25.000 – 45.000 |
| Produto completo (o que você está montando) | R$ 60.000 – 120.000 |
| Versão SaaS multi-tenant + billing + suporte | R$ 150.000 – 300.000+ |

Horas típicas de um time sênior: **400–900h** até um SaaS estável.

Você já tem boa parte do caminho (bot, proposta, schema, APIs). O valor restante está em: polish UX, multi-tenant SaaS, billing, estabilidade WhatsApp e vendas.

## Quanto cobrar do cliente final

### Modelo A — Licença / setup (agências)
- Setup + customização: **R$ 8.000 – 25.000**
- Mensalidade: **R$ 497 – 1.997**/mês (usuários + volume WhatsApp)

### Modelo B — Você usa internamente e vende o *serviço*
- O TERON é seu diferencial de entrega
- Projetos: **R$ 5.000 – 40.000+** com proposta gerada no próprio OS
- Mais fácil de monetizar agora

### Modelo C — White-label do bot
- Por nicho (barbearia, clínica): **R$ 197 – 497**/mês por tenant
- Escala diferente (volume, não ticket alto)

## Opinião direta

**Pontos fortes**
- Problema real (orçamento no WhatsApp é caos)
- Stack moderna e coerente
- Fluxo ponta a ponta é raro no BR
- Dá para usar em você primeiro (dogfooding) e só depois SaaS

**Riscos**
- WhatsApp (ban, API oficial vs não oficial)
- Concorrência parcial de CRMs grandes
- Produto amplo: precisa focar num ICP e numa jornada
- Manutenção alta se virar multi-tenant cedo demais

**Recomendação**
1. Use o TERON **em você** para fechar 5–10 projetos reais
2. Grave cases (tempo de proposta, taxa de aceite)
3. Venda como **"sistema da sua agência"** ou setup para 3–5 studios amigos
4. Só depois abra SaaS self-service

Posicionamento sugerido:
> *"Do primeiro oi no WhatsApp até a workstation do cliente — um único sistema para studios de software."*
